# WK S1.4 follow-up

Date: 9 September 2026

## Purpose

Re-test the strongest WK candidates at physical-height scale S1.4, using the established staged method: centre-only low-cost screening, denser useful-white visibility validation, then high-resolution three-view scoring for the surviving candidates.

Current benchmark remains `WWK / W0.24 / K0.16 / S1.30 / V77 / H0` = B/A/C 100/100/100, pitch 2.24088 mm, weighted dark band 1.72593 mm.

## Important visibility result

Simply changing the earlier S1.3 finalists to S1.4 is not valid in every case. Several V78 cases that looked feasible with coarse white-surface sampling fail the denser visibility check because the taller K cap blocks too much useful white. Therefore the S1.4 landscape was locally re-optimised rather than forcing the original S1.3 V values.

The strongest contrast point is `WK / W0.220 / K0.140 / S1.40 / V74 / H0`: weighted contrast is about 0.66% above the WWK benchmark, ambient return about 10.3% lower, but brightness about 9.7% lower. Pitch is about 37.5% smaller and weighted viewer dark band about 34.9% smaller.

The best balanced S1.4 candidate is `WK / W0.215 / K0.120 / S1.40 / V76 / H0`: weighted contrast about 0.33% above benchmark, brightness only about 4.2% lower, ambient about 4.6% lower, pitch about 39.7% smaller, and dark band about 38.0% smaller.

Per-view contrast for W0.215/K0.120/S1.40/V76 is approximately 111.35 / 101.34 / 96.77 for left / centre / right relative to the corresponding WWK benchmark views. The centre-heavy weighted result is 100.33.

## Conclusion

S1.4 improves the WK architecture materially when the W/K/V parameters are re-tuned. Unlike the best S1.3 WK cases, the strongest S1.4 candidates can match or slightly exceed the current WWK benchmark in weighted model contrast while retaining roughly 38-40% smaller pitch and dark-band geometry.

The most attractive physical test candidate from this follow-up is `WK / W0.215 / K0.120 / S1.40 / V76 / H0` because it keeps substantially more brightness than the absolute best-contrast S1.4 point while still slightly exceeding benchmark contrast in the model.

These are model predictions, not physical measurements.
